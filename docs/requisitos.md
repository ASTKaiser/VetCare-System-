# Requisitos del Sistema de Citas - Clínica Veterinaria

## Requisitos Funcionales (RF)
1. **RF01:** El sistema debe permitir registrar clientes nuevos.
2. **RF02:** El sistema debe permitir registrar mascotas asociadas a un cliente.
3. **RF03:** El sistema debe permitir agendar citas veterinarias.
4. **RF04:** El sistema debe permitir modificar citas registradas.
5. **RF05:** El sistema debe permitir cancelar citas.
6. **RF06:** El sistema debe permitir consultar horarios disponibles.
7. **RF07:** El sistema debe permitir registrar veterinarios.
8. **RF08:** El sistema debe mostrar las citas programadas por fecha y hora.
9. **RF09:** El sistema debe evitar la duplicación de citas en el mismo horario.
10. **RF10:** El sistema debe permitir buscar clientes, mascotas y citas registradas.

## Requisitos No Funcionales (RNF)
1. **RNF01 (Usabilidad):** El sistema debe ser fácil de usar para recepcionistas y personal administrativo.
2. **RNF02 (Rendimiento):** El sistema debe responder en un tiempo corto al consultar o guardar información (< 3 segundos).
3. **RNF03 (Seguridad):** El sistema debe proteger los datos de clientes, mascotas y citas.
4. **RNF04 (Disponibilidad):** El sistema debe estar disponible durante el horario de atención de la clínica.
5. **RNF05 (Mantenibilidad):** El sistema debe permitir futuras mejoras y correcciones con facilidad.
